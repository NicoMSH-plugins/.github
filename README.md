## Welcome! 👋

Open-source tools, UI enhancements, and security scripts built for **KeyHelp** server administration and **Owncast** streaming setups.

### Featured Projects

* **[KeyHelp Dashboard Layout Customizer](https://github.com/NicoMSH-plugins/keyhelp-dashboard-layout-customizer)**  
  Drag-and-drop dashboard layout editor with per-language persistence, widget visibility toggles, and custom status widgets.
* **[KeyHelp Kernel IPSet Firewall](https://github.com/NicoMSH-plugins/keyhelp-kernel-ipset-firewall)**  
  High-performance IPSet kernel firewall script for KeyHelp to block AbuseIPDB and FireHOL lists in seconds, including live traffic and packet statistics.
* **[Owncast User Last Seen](https://github.com/NicoMSH-plugins/owncast-user-last-seen)**  
  Extension and tracking tools for Owncast instances.

---

### Focus Areas
* **Server & Panel Tooling:** Lightweight JavaScript, PHP, and Shell integrations for KeyHelp.
* **Network Security:** Automated IPSet blocklists and kernel-level filtering.
* **Streaming Infrastructure:** Monitoring and add-ons around Owncast.
